# B3：离线混合编辑实验

B3 是可运行的**实验算法**，未接入正式出版、Shadow、WebDAV 或数据采集；无外部调用、模型下载或额外依赖。它不是已验证的国际新闻重要性模型。通过合成测试或一次公开数据实验，不代表真实编辑质量提高。

## 可运行路径

```sh
python -m scripts.editorial_v2.replay tests/fixtures/editorial_v2/synthetic_snapshot.json --b2 --b3
python -m scripts.editorial_v2.crossnews_eval /local/path/crossnews-ua.csv
```

`--b2`、`--b3` 通过已有 replay 各自运行算法；B0/B1 仍是输入中已记录的结果，未记录就不会伪造。对授权私有密文，原有 `--encrypted-private` 同样可在本地运行 B3；不发送数据。`b3.select(candidates, captured_at, capacity)` 直接返回候选 ID、分组和选择；diagnostics 只包含 ID、命中类别、未校准分数和 `unverified_heuristic`，不包含原文或模型输出。公开日志仍不可包含私人输入或可关联 ID。候选顺序、标签及运行后的正文质量不进入排序，结果按候选 ID 稳定处理；每个已识别事件最多一篇。

## 已实现方法

1. 同稿：沿用 B2 保守 URL 规范化，保留语义查询参数；URL 缺失不推断同稿。
2. 事件：已知合法发表时间相差不超过 72 小时，或双方正文前置可见文本各有唯一、相同窗口内的明确 ISO 事件日期；时间缺失、歧义或未来日期均保留 unknown。标题至少两个共同专名/实体锚点，并含经小型词表映射的同一动作（例如法语/英语袭击）；双方若各有冲突的其他实体锚点则弃判。同语言额外要求词汇重合；完全链接阻止弱关联传递扩张。跨语言词表极小、实体仅用大写规则及有限西里尔字母转写；不支持可靠中英文语义对齐，也无法保证同一人/地点不同转写一致。组 ID/结果不使用人工 gold。
3. 重要性与组合：对安全、国际关系、经济、科技、公共卫生、气候等少量词语记录**可观察提示**，仅为无监督代理信号，不等于影响大小、来源可靠性或事实证据；未命中的事件仍有入选机会，不设地域/媒体/语言/领域硬配额，不按报道数量计重要性。基于提示、时效、未覆盖提示及共享实体惩罚做确定性贪心边际选择，再做一次有界的单项最佳替换检查。该启发式可能误排、漏报或过度偏向词表命中，需真实数据校准。
4. 代表文章：同组中按已获许可的 RSS 摘要长度、有效时间和 ID 选择；这些是信息可用性代理，不声称读取了全文或证实了媒体可靠性。B0 抓取后的质量绝不输入；B3 质量结果保持 unknown。

精度优先的设计仍可能误合并：两个不同事件可能共享地点、人物及动作。事实不明时保留独立候选，不能将这些 heuristic 当作语义识别或重要性裁判。临时增加模型或放松时间条件都需要新的固定集验证。

## 真实公开数据的首次离线实验

[CrossNews-UA 官方数据卡](https://huggingface.co/datasets/ukr-detect/crossnews-ua) 标注 CC BY 4.0；[项目仓库](https://github.com/TUM-NLP/crossnews-ua) 提供原始 CSV 和标注说明。使用项目仓库提交 `c4fa567661f5a42959fa3b458763ac48271f14eb`，CSV SHA-256 `4a8fde8f4c6bcbfe23b314833acc74cba76d58448d0db03350f3b8b044688edb`。原始新闻可能仍受出版商权利约束；本 PR 只保存[聚合结果](data/b3_crossnews_public_2026-11-24.json)，不重新发布原始文章、摘要或数据集副本。数据的进一步分发/商用必须单独核验许可。

CSV 共有 500 对；取跨语言且标注 `similar` 或 `different` 的 **213 对**（14/199），排除同语言及 `somewhat_related`、`disagreement` 共 287 对。`aggregated_what` 是主题/事件相似度**代理标签**，不是严格人工事件等价标签；这些对不是完整日报或独立事件集合。该 CSV 没有文章标题和发表时间，实验只在本机取每条原文前 800 字符作为输入代理，不伪造发布时间，不使用作者提供的 AI 摘要或标注作为输入。对聚类指标，将 B3 `unknown` 当作未合并：

| 方法 | TP | FP | FN | TN | 精确率 | 召回率 | F1 | B3 弃判 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| B2 | 0 | 0 | 14 | 199 | 未定义 | 0 | 0 | 不适用（布尔输出） |
| B3 | 0 | 0 | 14 | 199 | 未定义 | 0 | 0 | 213 |

在本执行环境的一次本地运行，213 对约 0.31 秒、进程峰值约 14 MiB；这些不是可移植性能承诺。无日期导致时间规则无法工作，结果**没有证明 B3 提升**；需要具有合法时间及事件标签的数据重测。该数据没有新闻重要性、正文质量和日报组合 gold，不能据此评价重要性排序、代表质量或边际覆盖。B0/B1 的真实结果不可得，不能用合成结果冒充对照。

另一候选 [OG2021 public](https://www.clarin.si/repository/xmlui/handle/11356/1922) 明确标注 CC BY-NC-ND 4.0，提供多语言标题、时间和事件聚类；本次公开下载请求返回 403，未绕过限制，也未将其数据加入仓库。未来可由用户在符合许可的环境取得原始数据并复验；ND/NC 及出版商权利限制需单独审查。

## 下一步验收边界

优先取得有明确研究许可、可靠时间及同/不同具体事件标签的固定集，预先冻结拆分、阈值、时间窗口和评价口径；人工标注重大事件、实质更新、代表文章质量与争议，比较 B0/B1/B2/B3 的覆盖、误合并、误拆分、增量重复、成本及顺序稳定性。未满足许可、跨语言误合并或重大事件漏报门槛时，停止生产实施。真实 Benchmark 尚未启用；不调用收费 AI、不修改 Secrets、配置或正式日报。
