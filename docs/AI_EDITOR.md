# AI Shadow Editor

Shadow runs only **after** the normal EPUB generation, dedup save, and delivery. It analyses RSS candidates and does not modify publication, history, delivery, or the EPUB. `AI_EDITOR_MODE=off` is the default and makes no DeepSeek request. `shadow` produces `ai-editor-report.json` and `ai-editor-summary.md` as a seven-day artifact. These files contain public candidate titles and source names; treat artifact access appropriately. The model sees only an ID, title, source name, language, date, RSS excerpt, and compact editorial profile. It is never given URLs, full articles, WebDAV credentials, tools, or raw feedback. Reports replace free-text model reasons with a locally computed score explanation to reduce leakage of private profile text.

Set the `DEEPSEEK_API_KEY` repository secret yourself, then opt in using repository variable `AI_EDITOR_MODE=shadow` or manual `ai_editor_mode_override=shadow`. Do not place credentials in configuration files. Manual `test_mode` never calls the API unless `run_ai_shadow` is explicitly checked. CI uses only mock transports. A provider failure produces a degraded report and cannot fail the daily step.

Defaults: `DEEPSEEK_MODEL=deepseek-flash`, `AI_MAX_CANDIDATES=200`, `AI_MAX_BATCH_CANDIDATES=40`, `AI_MAX_CALLS_PER_RUN=6`, `AI_MAX_INPUT_TOKENS=80000`, `AI_MAX_OUTPUT_TOKENS=8000`, `AI_MAX_TOTAL_TOKENS=88000`, `AI_TOTAL_TIMEOUT_SECONDS=60`, `AI_MAX_EXCERPT_CHARS=600`. Set these as repository variables to adjust them. Request reservations include conservative byte-based input estimates and maximum output; uncertain timeout calls retain their reservations. API usage is reported separately. The provider's tokenizer and usage accounting are outside this application's control; these guards are conservative estimates, not a billing guarantee. Optional `AI_INPUT_PRICE_PER_MILLION`, `AI_OUTPUT_PRICE_PER_MILLION`, and `AI_PRICING_VERSION` produce an estimated cost; prices are not embedded.

The report is RSS-only and compares ranked candidates to actual publication. The editor prioritizes global impact separately from local importance. Local weights are importance 25%, global impact 25%, depth 15%, information gain 10%, timeliness 10%, perspective 10%, and personal fit 5%. With no active personal preferences, personal fit is fixed at 50. Region and law labels carry no direct score bonus. Confidence reflects title/excerpt-only evidence. Event-level recommendations remain observational and never remove official articles. A second, optional composition pass groups up to 60 high-ranking candidates into real-world events without sending excerpts; it uses the same call and token budgets. On failure or insufficient budget the editor falls back to initial event hints. One representative is preferred for each event; at most two articles are selected per event, and the second requires analysis, an update, or a different angle. Must-cover events receive priority and source, region, and topic diversity are soft constraints. Because model clustering is uncertain, fallback may still miss duplicates. The report distinguishes candidate-cap coverage from actual budget exhaustion and includes event concentration diagnostics. `event_grouping_source` identifies whether those diagnostics use the composition result or fallback hints; neither proves the true number of real-world events. Missing or unreadable memory uses default constraints and reports degraded memory. Malformed responses, rate limits, timeouts, and missing keys stop or degrade AI without changing delivery.

For the first real test: configure the secrets and independent memory key as described in AI_MEMORY.md, choose **Daily Gather** on this branch, use `test_mode` plus `run_ai_shadow` and select `shadow`, then inspect the artifact and billing. This explicit choice can incur API charges; ordinary CI never does so. Do not enable test override merely to test publication.

Optional variables: `AI_COMPOSE_MAX_CANDIDATES` defaults to 60 (ceiling 100); `AI_MAX_ARTICLES_PER_EVENT` defaults to 2 and cannot exceed 2. Existing budget variables and defaults are unchanged. No region has a fixed quota.
